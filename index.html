1. Characteristics of computers and five generations

Question. List four primary characteristics of a modern digital computer and identify the key hardware technology associated with each of the five generations of computers.

Four characteristics

  1. Speed: Executes very large numbers of instructions in a short time.
  2. Accuracy: Produces precise results when its input, instructions, and hardware are correct.
  3. Storage: Holds programs and data for immediate use in memory and for long-term use in storage devices.
  4. Automation: Follows a stored program to complete a sequence of operations with little intervention.

Hardware across generations

Common textbook classification of computer generations
GenerationKey hardware technologyWhat changed
FirstVacuum tubesElectronic switching replaced mechanical switching; systems were large and power hungry.
SecondTransistorsSmaller, cooler, and more reliable switching.
ThirdIntegrated circuits (ICs)Multiple electronic components were fabricated on a chip.
FourthMicroprocessors built with large-scale integrationThe CPU could fit on one chip, enabling personal computers.
FifthVery-large-scale integration (VLSI/ULSI) and parallel-processing hardwareDense chips and multiple processors support advanced computing, including AI applications.

Note: “Fifth generation” is a broad textbook label associated with AI-oriented computing; it does not denote one exclusive chip type.

2. Flow through the functional block diagram

Question. Explain the flow of data, instructions, and control signals within the functional block diagram of a computer, detailing the interaction between the CPU, memory unit, and I/O interface.

  1. Input: The I/O interface receives device data, converts or buffers it as needed, and makes it available to memory or the CPU.
  2. Fetch: The CPU's control unit sends an address to memory and a read signal. Memory returns the instruction on the data bus.
  3. Decode and execute: The control unit interprets the instruction. The CPU fetches required data; its arithmetic logic unit (ALU) performs the operation using registers for immediate values.
  4. Store and output: The CPU sends a result to memory with a write signal, or sends it through the I/O interface to an output device.

Three kinds of signals: The address bus selects a memory location or device; the data bus carries instructions and values; and the control bus carries read, write, timing, and other coordination signals. Devices may also send an interrupt to request CPU attention.

Language categories compared
CriterionMachine languageAssembly languageHigh-level language

6. Output system for civil engineering blueprints

Question. Assess whether a drum/flatbed plotter or an ultra-high-definition monitor and large-format printer combination is superior for producing civil engineering blueprints, justifying your selection based on line resolution, scalability, and long-term production costs.

Selection: For a typical modern civil engineering office, use a high-resolution monitor for on-screen review and a large-format technical printer for final sheets. Keep a pen plotter only if a specialized workflow specifically needs its pen-drawn output.

Trade-offs for plan production
CriterionDrum / flatbed pen plotterMonitor + large-format printer
Line resolutionDraws continuous vector paths with a physical pen; line quality depends on pen width, paper, calibration, and condition. Excellent for clean line work, but slower with dense fills and images.The monitor lets staff inspect fine CAD details before printing. A technical printer produces controlled line weights and also handles text, hatching, color, and raster imagery; output quality depends on the device and chosen resolution.
ScalabilityHandles supported sheet sizes, but pen changes and mechanical drawing time limit throughput for complex or repeated plans.CAD files can be reviewed, revised, shared, and printed at multiple supported sheet sizes. Batch printing and mixed-content plans are easier to manage.
Long-term costSpecialized pens, mechanical upkeep, and slower production can raise labor and maintenance costs.Printer, ink/toner, media, and servicing cost money, but faster revisions and higher throughput usually lower the cost per routine office drawing over time.

Qualification: Neither an ultra-high-definition screen nor a printer's advertised dots per inch guarantees accurate scale. Check CAD line weights, page size, print scale, device calibration, and a sample sheet before issuing drawings.

Reliability and security in an open, noisy setting
IssueFacial recognitionVoice recognition

8. Accessible hands-free workstation

Question. Design an accessible, hands-free computer workstation tailored for a visually impaired user. Propose a coherent integration of non-visual input devices (such as voice recognition systems and tactile keyboards) with specialized output devices (such as voice response synthesizers and screen readers).

Proposed setup: A computer with a microphone headset, speech-recognition commands, a screen reader with text-to-speech, a tactile keyboard for optional backup input, and headphones or a discreet speaker. An optional refreshable Braille display supports precise reading where useful.

  1. Start and orient: On sign-in, the screen reader announces the current window, focused control, and available actions. A spoken command such as “open notes” launches the requested application.
  2. Navigate: Speech commands move focus to headings, links, fields, and buttons. The screen reader announces labels and state so the user knows what is selected.
  3. Write: Dictation enters text. The user can say commands such as “new paragraph” and “read last sentence”; the synthesizer reads the result for correction.
  4. Confirm actions: The system repeats high-impact actions, such as sending a document, and waits for a clear “confirm.” Spoken status messages report success or an error.
  5. Recover: A tactile keyboard with familiar key landmarks and screen-reader shortcuts remains available if recognition fails or speech is inappropriate. Braille output can help with spelling, punctuation, code, and private text.

Integration requirements: Use applications with accessible names and keyboard focus order; let the user change speech rate, voice, and volume; support a push-to-talk control to reduce accidental commands; provide headphones for privacy; and offer a non-biometric sign-in method. “Hands-free” is the primary workflow, while tactile input is an optional reliable fallback.
